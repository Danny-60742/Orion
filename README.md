# Orion v1

Orion is a lightweight terminal assistant written in Python.

## Features

- 🕒 Tell the current time
- 📅 Tell the current date
- 🧮 Basic calculator
- 🌍 World clock
- 📊 Status command

# Installation

Clone the repository:

```bash
git clone https://github.com/Danny-60742/Orion.git
```

Install the Python dependencies:

```bash
pip install rich requests tzdata
```

(Optional) Install `figlet` and `lolcat` for the colored startup banner.

Ubuntu/Debian:

```bash
sudo apt install figlet
sudo gem install lolcat
```

Run Orion:

```bash
cd (directory containing Orion)

python main.py
